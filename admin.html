キャラクター管理

ここからキャラクターの追加・編集・削除ができます。保存するとあなたの GitHub リポジトリに直接反映され、1〜2分ほどでサイトに表示されます。 サイトを見る

① GitHub との接続

トークンはこの端末のブラウザにだけ保存され、GitHub 以外には送信されません。トークンの作り方は README を見てください。

② 登録済みのキャラクター

タップで編集できます。並び替えは、カードを長押ししてから動かしてください。終わったら「並び順を保存する」を押してください。

③ キャラクターを追加

受け・攻め（ボタンで選択。もう一度押すと未設定に戻ります）

プロンプト関連の項目は「代理」か「うちよそ」タグを付けたキャラクターだけに表示されます。

公開ページではモザイクがかかり、タップすると内容が見える形で表示されます。

プロットURL（公開ページの目立つ場所にボタンで表示されます）

「プロット」を付けると、「プロット紹介」と「プロットURL」の入力欄が出てきます。

いまの画像(チェックを外すと削除されます)

④ 推しプロット紹介

「推しプロット紹介」ページに表示される一覧です。サムネ画像をアップロードしない場合は、リンク先のスクリーンショットが自動で表示されます（サービスによってはログイン画面などが写って正しく表示されないことがあります。その場合は画像のアップロードがおすすめです）。 ページを見る
