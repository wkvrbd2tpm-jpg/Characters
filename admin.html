キャラクター管理

ここからキャラクターの追加・編集・削除ができます。保存するとあなたの GitHub リポジトリに直接反映され、1〜2分ほどでサイトに表示されます。 サイトを見る

① GitHub との接続

トークンはこの端末のブラウザにだけ保存され、GitHub 以外には送信されません。トークンの作り方は README を見てください。

② 登録済みのキャラクター

順番は ⤒（一番上）↑ ↓ ⤓（一番下）のボタンで変えられます。押してもすぐには保存されないので、並べ終わったら下の「並び順を保存する」を押してください。

③ キャラクターを追加

受け・攻め（ボタンで選択。もう一度押すと未設定に戻ります）
プロットURL（公開ページの目立つ場所にボタンで表示されます）

「プロット」を付けると、「プロット紹介」と「プロットURL」の入力欄が出てきます。
